# C Programming Practice

Beginner C programs for Hello World, odd/even checks, a switch-based calculator, and palindrome checks.

## Compile and run on Windows

Install GCC and make sure `gcc` is available in your terminal. From the project folder, run:

```powershell
.\run.bat hello
.\run.bat odd_even
.\run.bat calculator
.\run.bat palindrome
```

The runner compiles the matching `src\<name>.c` file into `build\<name>.exe` and runs it.
